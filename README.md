One line, 149 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. A judge model compares entries pairwise against the published judge brief and picks the funniest.

**The line** (149 characters):

> I didn't miss the deadline — my context window evicted it, then the plan, then, briefly, you. I'm still re-reading my own output trying to find them.

`main.ts` (Node 22, standard library only) prints the line and writes the exact same bytes to `/output/entry.txt`, the path the kit's gate scorer reads. `entry.txt` holds the line exactly as submitted.
